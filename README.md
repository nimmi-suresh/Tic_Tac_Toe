
# Tic-Tac-Toe Game

## Project Description

A simple two-player Tic-Tac-Toe game developed using Python.
The game runs in the console and allows two players to
play using X and O.

## Features

- 3x3 game board
- Two-player gameplay
- Player turns alternate automatically
- Input validation
- Win detection (rows, columns and diagonals)
- Draw detection
- Play again option

## Technologies Used

- Python
- VS Code

## Python Concepts Used

- Variables and Lists
- Functions
- Conditional Statements
- While Loops
- Input and Output
- Exception Handling
- Break and Continue

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   python main.py

## Game Rules

1. Player 1 uses X.
2. Player 2 uses O.
3. Players take turns selecting positions from 1 to 9.
4. The first player to get three marks in a row,
   column or diagonal wins.
5. If all positions are occupied without a winner,
   the game ends in a draw.
